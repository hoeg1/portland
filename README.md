# Portland
　Portland はドイツのゲームデザイナー Reiner Knizia 氏が考案した面白いトランプ・ゲームです。各プレイヤーは毎度ソーシャルゲームのガチャゲーを思わせる運試しを迫られますが、ソシャゲと違っていくら遊んでも破産の心配はありませんし、カウンティングと確率計算はあなたを勝利に導きます。


　[遊ぶ (Play Online)](https://hoeg1.github.io/portland/)


　実装にあたり、引き分けや各ラウンド最初の手番等、正しい処理がよくわからない部分については [ゲームファーム](https://gamefarm.jp/rule/portland.html) の記事を参考に独自の解釈を加えました。

　この解釈を正しいとする根拠はまったく無いので、本作のルールが変だと感じた方は原典を参考に思い思いのルールを楽しんでください。
