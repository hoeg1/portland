# Portland
　Portland はドイツのゲームデザイナー Reiner Knizia 氏が考案した面白いトランプ・ゲームです。各プレイヤーは毎度ソーシャルゲームのガチャを思わせる運試しを迫られますが、ソシャゲと違っていくら遊んでも破産の心配はありませんし、綿密なカウンティングと確率計算は、ソシャゲと違ってあなたを勝利に導くでしょう！

　[遊ぶ (Play Online)](https://hoeg1.github.io/portland/)

　実装にあたり、引き分けや各ラウンド最初の手番等、正しい処理がよくわからない部分については [ゲームファーム](https://gamefarm.jp/rule/portland.html) の記事を参考に独自の解釈を加えました。

　ただし上記の解釈が正しいとする根拠はまったく無いので、本作のルールが変だと感じた方は、原典を尊重し「これぞ」と思うルールを楽しんでください。このアプリの解釈はクニツィア博士が披露なされたオリジナル・ルールの１ヴァリアントに過ぎません。

　このアプリではさらに、上記の曖昧さにつけ込んで以下のヴァリアント・ルールを有効にしています。


### オプション１: ６人以上でのプレイ

　本来のポートランドは５人までのゲームですが、理論上は１０億人でもプレイ可能です。よって、本アプリではブラウザ版で８人、コンソール版では９人まで遊べるようにしています。

　９人プレイを試したい方はこのプロジェクトをダウンロードし、node.js をインストールした上で次のコマンドを入力してください。なお、コンソール版ではランク 10 が T の字で表現されます。

```shell
node tui.js -p9
```

### オプション２: ５ラウンドルール

　オリジナルは６ラウンドですが、このオプションではゲームが５ラウンドで終わります。これはポートランドをご存知のプレイヤーなら一度は試したくなるヴァリアントのはずです。

　試してみると、近視的には劇的な変化が無いように感じます。しかし１ゲームを通してみると本来のゲームが持っていた鋭さが失われたような印象を受けるはずです。

　筆者はアホなのでわかりませんが、ライナー・クニツィア数学博士がこのゲームを「６ラウンド」としたことには何からの明確な理由があるのだろうと感じます。
