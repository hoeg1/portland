Reiner Knizia's Portland

　ポートランドはドイツのゲームデザイナー Reiner Knizia 博士が発明した ガチャゲー ポーカーゲームです。

　各プレイヤーは５２枚の普通のトランプを持ってゲームに参加し、毎回、自分の山札からカードを「めくる」か「パス」するかを決めます。

　めくる場合はめくったカードと５枚の手札のどれか１枚を交換します。これによって手札が強くなるかもしれませんが、全６ラウンドのゲームの最初には必ず５枚のカードを使うので、引きすぎてしまうと後のラウンドで手札不足に苦しみます。しかも、ポーカー勝負に勝ったときの得点は後のラウンドのほうが高くなるのです。

　パスを選んだプレイヤーはそのラウンドが終わるまで一旦ゲームを抜けます。手札の浪費を避けられますが、そうして逃げてばかりでは高得点は望めません。

 

ゲームの準備

　参加する全プレイヤーがジョーカーを除いた普通のトランプ１組５２枚を持ち、よく切って山札にします。各プレイヤーが持つこの札を「個人の山札」と呼びます。

 

ラウンドの開始

　全員一斉に５枚のカードを個人の山札からめくり、目の前に表向きにします。これを各プレイヤーの「手札」と呼びます。手札は隠しません。全員が他のプレイヤーの手札を見ることができます。

　適当に選んだ最初のプレイヤーから最初のプレイを始めます。

 

プレイ

　手番プレイヤーは次のどちらかひとつをします。

  • 自分の山札をクリックして１枚めくる

    　めくることにしたプレイヤーはめくられたカードを自分の手札１枚と交換します。交換された手札は裏向きに捨て札されます。

    　めくったカードを交換せず捨てることはできません。必ず手札のどれか１枚と交換します。

  • パスする

    　山札が無い場合、または交換したくない場合は「PASS」ボタンを押してパスします。

    　パスを選んだプレイヤーはラウンドが終わるまで手番をスキップされます。全員が「パス」を選んだらラウンド終了で、得点計算をします。

 

得点計算

　各プレイヤーは自分の手札のポーカー役を他人と比べて順位を決定し、次のように得点計算します。

 

n = 参加人数 - 1

P(n) = n × ラウンド数

 

　として、１位のプレイヤーは P(n) 点、２位のプレイヤーは P(n-1) 点を得ます。つまり P(参加人数 - 自分の順位) だけ得点するということです。最下位のプレイヤーは n = 0 になるため、ラウンド数によらず常に０点です。

 

　得点が済んだら全プレイヤーは手札を裏向きに捨て、最初の５枚を個人の山札から引き、１位だったプレイヤーが最初の手番になって次のラウンドを始めます。

 

●最初の５枚を引きたいのに山札が足りないとき

　ラウンドを進めていくと上で説明した最初の手札が５枚未満になることがあります。

　山札が０枚の時点で以降のラウンドでは「パス」しかできませんし、そのようなプレイヤーの手札はフラッシュやストレートを要求する役を作れなくなります。さらに、ペア系の役は依然として有効ですが、そうした役は手札を５枚使っている役より 常に弱い 判定を受けます。

　例えばペア系で最強の役「フォーカード」を４枚の手札で作っても、そのフォーカードは５枚の手札で作れる役の最弱たる「ハイカード」に負けます。同様に、４枚の手札で作ったワンペアは３枚の手札で作ったスリーカードに勝ちます。

　ほとんど勝ち目がなくなるので、最初に手札５枚を引けるようプレイしましょう。

 

●タイブレーク

　手札の枚数が５枚でない場合のルールは上記の通りですが、得点計算のときに２人以上のプレイヤーが同じ役だった場合は、普通のポーカーと同様に「役を構成している部分の強さ」を比べてランクが強いほうが勝ちになります。ランクの強さはＡが最強で、以降Ｋ、Ｑ、Ｊ、10 ... ３、２の順です。

　例えばあなたの手札が「ＡＡＡ５３」で、相手が「ＫＫＫ５２」なら、スリーカードを構成している部分が Ａ ＞ Ｋ のため、あなたの勝ちです。

　上記のやり方でも勝負がつかないときは「役にならないカードのランク」を比べます。例えば上記のスリーカード勝負が、あなたが「ＡＡＡ５３」、相手が「ＡＡＡ５２」なら、揃っていない２枚のうち強いほうから比べて「５」については同点、しかし ３ ＞ ２ のため、あなたの勝ちと判定します。

　なお、Ａが最強というルールはストレートの場合必ずしも成立しません。ストレートでは「ＡＫＱＪ10」が最強、「５４３２Ａ」が最弱になり、Ａの価値が他の４枚で変わります。

 

　それでも勝負がつかなかったとき（２人のプレイヤーが完全に同じ強さの手札だったとき）は引き分けです。

　引き分けになった場合は、例えば全体で２位の強さを持つ３人がいるなら、

 

（２位の点＋３位の点＋４位の点） ÷ ３人 ※端数切り捨て

 

　という点数が該当する全員に入ります。手札の強さがそれより弱かったプレイヤーは５位以降の得点を得ます。

 

　１位のプレイヤーが複数いるときはもう少し複雑です。１位のプレイヤーは次のラウンドのスタートプレイヤーになりますが、１位が複数いる場合は前のラウンドのスタートプレイヤーから席順で最も近い位置にいるプレイヤーがスタートプレイヤーになります。

 

　上記のタイブレークは Knizia 氏のルールではなく、ゲームファーム の推奨ルールを参考にしています。

 

ゲームの終了

　全６ラウンドをプレイし終えたとき、累計得点が最も多かったプレイヤーの勝ちです。同点なら引き分けです。

 

オプション: 5ʀ Game

　ポートランドの基本ルールではラウンドは全６ラウンドです。各プレイヤーは毎ラウンドの始めに５枚の手札を使うので、５枚×６ʀ ＝ ３０枚はこのために消費され、「めくる」ことができるカードは５２ - ３０ = ２２枚になります。２２枚÷６ʀ は約 3.7 枚です。

　つまり各プレイヤーは１ラウンドあたり平均して３から４枚の手札を交換するのが精一杯なわけですが、ゲームが５ラウンドで終わりならどうでしょう？

　５ラウンド勝負のオプションはこのためにあります。山札をめくる機会が約１枚増えるので、普通のルールに飽きたら試してみてください。

 

５枚の初期手札 × ５ʀ ＝ ２５枚

( ５２枚 - ２５枚 ) ÷ ５ʀ ≒ ５．４枚 => 各ラウンドで５枚は引けます

 

 

ＣＰＵについて

　対戦相手はラウンダムに選ばれ、名前ごとにある程度の個性を持ちます。そうした上で、全ＣＰＵは指定したレベルによってベースとなる強さを変えます。

  • Random: ＣＰＵごとにランダムなレベルを設定します。

  • Lv.1: 引きすぎないようにしつつ他人よりよい手を目指します。

  • Lv.2: 引くかパスかを期待値で判断します。

  • Lv.3: ラストラウンドで粘ります。他はLv.2と同様です。

  • Lv.4: 他人の山札も考慮して行動します。

　なお、このゲームは不正をしません。ＣＰＵは自分に有利な手札を恣意的に引いたりできないし、ゲームシステムはあなたにだけ不利な手札を配ったりしません。ＣＰＵらが結託し、あなただけを攻撃することもありません。ストレートを諦めた直後に待っていたカードを引いたりすると不正を疑いたくなるかもしれませんが、ただの偶然です:)
